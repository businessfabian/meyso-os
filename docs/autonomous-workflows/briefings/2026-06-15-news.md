### Dringendes Sicherheitsupdate für Next.js (betrifft 16.1.6)
**Was:** Mehrere kritische Sicherheitslücken, darunter ein Authentifizierungs-Bypass (CVE-2026-44574) und Server-Side Request Forgery (CVE-2026-44578), wurden in Next.js-Versionen vor 16.2.5 entdeckt.
**Impact fuer Dave:** Deine Version 16.1.6 ist anfällig; Angreifer könnten potenziell unauthentifiziert auf geschützte Routen zugreifen oder Anfragen an interne Netzwerke senden.
**Action:** Dringend updaten
**Datum:** Mai 2026
**Quelle:** [Is Your AI-Built App Exposed? Next.js Just Got 12 New CVEs](https://vibeaudits.com/blog/is-your-ai-built-app-exposed-next-js-just-got-12-new-cves)

### Vercel Drop: Git-loses Deployment per Drag-and-Drop
**Was:** Vercel hat am 12. Juni 2026 "Vercel Drop" veröffentlicht, ein neues Feature zum direkten Deployment von Ordnern oder ZIP-Dateien über den Browser, ohne dass eine Git-Anbindung erforderlich ist.
**Impact fuer Dave:** Du kannst Prototypen oder kleine Projekte für Kunden in Sekunden live schalten, ohne ein Git-Repository aufsetzen zu müssen.
**Action:** Ausprobieren
**Datum:** 12.06.2026
**Quelle:** [Vercel Drop: Drop it. It's live.](https://chatgate.com/p/vercel-drop-drop-it-its-live)

### Claude Code CLI Updates bis v2.1.169
**Was:** Die Claude Code CLI hat neue Befehle wie `/cd` zum Wechseln des Verzeichnisses mitten in einer Session und einen `--safe-mode` zum Troubleshooting ohne Customizations erhalten.
**Impact fuer Dave:** Du kannst Sessions einfacher verwalten und Fehler schneller eingrenzen, ohne die CLI neustarten oder die Konfiguration ändern zu müssen.
**Action:** Nichts tun (Updates kommen automatisch, gut zu wissen)
**Datum:** 08.06.2026
**Quelle:** [Claude Code v2.1.169 Major Updates](https://dev.classmethod.jp/articles/en/20260609-cc-updates-v2-1-169/)

### Supabase Auth unterstützt jetzt Passkeys (Beta)
**Was:** Supabase hat im Juni-Update native Passkey-Unterstützung für Supabase Auth als Beta-Feature veröffentlicht, was passwortlose Logins via Face ID, Touch ID oder Windows Hello ermöglicht.
**Impact fuer Dave:** Du kannst für deine Agency-Kunden und toolradar.de moderne und sicherere Authentifizierungsmethoden anbieten, die die Abhängigkeit von Passwörtern reduzieren.
**Action:** Ausprobieren
**Datum:** 10.06.2026
**Quelle:** [Supabase Passkeys: Drop Passwords From Your App Today](https://byteiota.com/supabase-passkeys-drop-passwords-from-your-app-today/)

### Gemini API führt "Flex"-Tier für 50% niedrigere Kosten ein
**Was:** Google hat am 1. Juni 2026 neue Inference-Tiers für die Gemini API eingeführt, darunter ein "Flex"-Tier, das eine Preisreduktion von 50% im Austausch für variable Latenz und geringere Zuverlässigkeit bietet.
**Impact fuer Dave:** Du kannst die Kosten für nicht-zeitkritische API-Aufrufe, wie z.B. Batch-Jobs für toolradar.de, potenziell halbieren.
**Action:** Ausprobieren
**Datum:** 01.06.2026
**Quelle:** [Gemini API's New Cost-Reliability Tradeoffs: What Developers Gain](https://egoistai.com/p/gemini-api-new-cost-reliability-tradeoffs-what-developers-gain)
