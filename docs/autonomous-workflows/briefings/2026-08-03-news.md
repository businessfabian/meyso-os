### Gemini API: 3.6 Flash als neuer Standard
**Was:** Google hat am 21. Juli Gemini 3.6 Flash angekündigt, ein neues "Arbeitstier"-Modell, das eine verbesserte Leistung bei Codierung und Wissensarbeit aufweist. Es ist effizienter und verbraucht bis zu 17% weniger Tokens als Gemini 3.5 Flash. Ein API-Update am 28. Juli hat dieses Modell als neuen Standard gesetzt.
**Impact für Dave:** Du kannst deine API-Calls auf das neuere, effizientere Modell umstellen, um potenziell Kosten zu sparen und die Leistung zu verbessern.
**Action:** Ausprobieren
**Datum:** 21.07.2026

### Neuer Trend: MCP Server für AI Agents
**Was:** Das "Model Context Protocol" (MCP) entwickelt sich zu einem offenen Standard, der es AI-Agents ermöglicht, externe Tools über einen Server sicher und einheitlich aufzurufen.
**Impact für Dave:** Anstatt für jeden Service eine eigene Integration zu schreiben, könntest du in Zukunft einen MCP Server nutzen, um deinen Agents standardisierten Zugriff auf Tools wie GitHub oder andere APIs zu geben.
**Action:** Nichts tun
