Hallo Dave, hier ist dein wöchentlicher Tech-Intelligence Report.

Diese Woche gab es wichtige Updates in deinem Stack, insbesondere ein kritisches Sicherheitsupdate für Next.js und ein neues Gemini-Modell.

### Dringendes Sicherheitsupdate: Next.js 16.2.6
Was: Next.js hat ein kritisches Sicherheitsupdate (v16.2.6) veröffentlicht, das 13 Schwachstellen schließt, darunter Middleware-Bypässe, Cache-Poisoning und Denial-of-Service.
Impact fuer Dave: Deine aktuelle Version 16.1.6 ist anfällig und sollte umgehend aktualisiert werden, um Sicherheitsrisiken zu vermeiden.
Action: Dringend updaten
Datum: Mai 2026
Quelle: [Next.js May 2026 security release](https://vercel.com/blog/next-js-may-2026-security-release)

### Neues Modell: Gemini 3.5 Flash ist GA
Was: Google hat mit `gemini-3.5-flash` ein neues, intelligenteres und auf Geschwindigkeit optimiertes Modell als General Availability veröffentlicht, das dein aktuelles `gemini-2.5-flash` ersetzen kann.
Impact fuer Dave: Du kannst deine API-Calls auf das neue Modell umstellen, um potenziell bessere Performance und Ergebnisse bei Agenten- und Coding-Aufgaben zu erhalten.
Action: Ausprobieren
Datum: 19.05.2026
Quelle: [Release notes | Gemini API](https://ai.google.dev/docs/release-notes)

### Breaking Change in Gemini Interactions API
Was: Die Gemini Interactions API erhält ein neues Response-Schema ("steps" statt "outputs"), das am 26. Mai 2026 zum Standard wird.
Impact fuer Dave: Wenn du die Interactions API nutzt, musst du deinen Code anpassen, da das alte Schema am 8. Juni 2026 endgültig entfernt wird.
Action: Dringend updaten
Datum: Mai 2026
Quelle: [Interactions API: Breaking changes migration guide (May 2026)](https://ai.google.dev/docs/migration-guide/interactions-api)

### Claude Code CLI Update v2.1.149
Was: Die neue Version des Claude Code CLI (v2.1.149) bringt einen detaillierten `/usage` Befehl und schließt Sicherheitslücken bei PowerShell.
Impact fuer Dave: Du kannst jetzt genau sehen, welche Skills und Plugins deine Nutzungs-Limits verbrauchen und arbeitest sicherer.
Action: Ausprobieren
Datum: 22.05.2026
Quelle: [Major Updates in Claude Code v2.1.149 to v2.1.150](https://dev.classmethod.jp/articles/claude-code-updates-v2-1-150/)

### Wichtige Änderung bei Supabase: Neue Tabellen sind standardmäßig nicht mehr öffentlich
Was: Ab dem 30. Mai 2026 werden neue Tabellen im "public" Schema nicht mehr automatisch über die Data API verfügbar gemacht.
Impact fuer Dave: Für alle neuen Projekte musst du explizit via Postgres Grants festlegen, welche Tabellen über die API erreichbar sein sollen, was die Sicherheit standardmäßig erhöht.
Action: Nichts tun
Datum: Mai 2026
Quelle: [Developer Update - May 2026](https://supabase.com/changelog/developer-update-may-2026)
