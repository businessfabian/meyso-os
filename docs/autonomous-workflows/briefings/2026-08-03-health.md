# Codebase Health Report 2026-08-03

## Tech Debt aus TASKS.md
Die offenen technischen Schulden in TASKS.md sind in mehrere Prioritätsstufen unterteilt:

*   **P0 - Sofort (Sicherheit + Rechtlich):** Hier stehen kritische Sicherheitsthemen im Vordergrund, darunter die Rotation mehrerer API-Keys (Gemini, PageSpeed, CRON_SECRET, GSC Service-Account, Resend, Admin-Passwort für sq-schmidt) aufgrund von Kompromittierung oder Leaks. Für Halveo sind das Eintragen der Telefonnummer im Impressum, das Versenden einer Beta-Mail und Smoke-Tests auf Produktion dringend.
*   **P1 - Diese Woche (Kunden + SEO):** Dieser Block konzentriert sich auf kunden- und traffic-relevante Aufgaben. Für Halveo sind ein Anwaltstermin für Legal-Review und das Branding des Stripe Customer Portals wichtig. Projektübergreifend stehen die Prüfung von Sanity CORS für Hirmax, Google Business Profile Updates, die Konfiguration von Social Media API Keys und der End-to-End-Test des Lexware Exports an.
*   **P2 - Nächste 2 Wochen (Tech Debt + Hardening):** Hier finden sich interne Aufräum- und Härtungsmaßnahmen. Dazu gehören Schema-Erweiterungen und UI-Verifikationen für Halveo, die Evaluierung von Finom Banking API, die Erforschung neuer Claude Code Features und Gemini API-Optimierungen (Spend Cap, neue Modelle). Kritisch sind auch die fehlenden GSC-Daten und unplausible Lighthouse-Werte im SEO-Agent-Report sowie ein ausstehender `npm audit fix` für hirmax. Ein großer Block widmet sich der rechtlichen Absicherung von Hirmax (DSGVO-Verarbeitungsverzeichnis, TOMs) und der Aktivierung von fünf AVVs (Vercel, Supabase, Resend, Sanity, Meyso-Hirmax).
*   **P3 - Feature Backlog (Kundenprojekte):** Dieser Bereich enthält zahlreiche wertschöpfende Features für Halveo (z.B. NKA-Modul, PDF-Exporte, OCR, Mieter-Portal), die Implementierung von Payment Processing für Hirmax, diverse Blog- und Monitoring-Features für Toolradar sowie Admin- und Cockpit-Erweiterungen für die meyso-website. Auch Infrastruktur-Verbesserungen wie manuelle Space Cleanups und die Evaluierung von pnpm/Turborepo sind hier gelistet.

Insgesamt gibt es eine hohe Anzahl offener Tasks, wobei die P0-Items die höchste Dringlichkeit besitzen.
