Es gab ein kritisches Security Release für Next.js und interessante Updates bei Supabase und den AI-APIs.

### Dringendes Security Release: Next.js 16.2.6
Was: Next.js hat die Version 16.2.6 veröffentlicht, die 13 Sicherheitslücken schliesst, darunter kritische Probleme wie Middleware-Bypass, Server-Side Request Forgery (SSRF) und Cache-Poisoning.
Impact fuer Dave: Deine aktuelle Version 16.1.6 ist verwundbar, was zu unautorisiertem Zugriff oder einem Denial-of-Service führen könnte.
Action: Dringend updaten
Datum: 07.05.2026
Quelle: [Next.js May 2026 security release](https://vercel.com/blog/next-js-may-2026-security-release)

### Supabase: Breaking Change bei Data API Exposure
Was: Ab dem 30. Mai 2026 werden neue Tabellen im `public` Schema nicht mehr automatisch über die Data API verfügbar gemacht; explizite `GRANT` Befehle sind dann nötig.
Impact fuer Dave: Bei neuen Projekten musst du die API-Erreichbarkeit pro Tabelle aktiv freischalten, was die Default-Sicherheit erhöht und unabsichtlich exponierte Tabellen verhindert.
Action: Nichts tun (für bestehende Projekte bis Oktober), aber für neue Projekte beachten.
Datum: Mai 2026 (Ankündigung), 30.05.2026 (Inkrafttreten)
Quelle: [Developer Update - May 2026 · Changelog - Supabase](https://supabase.com/changelog/developer-update-may-2026)

### Claude Code CLI: Opus 4.7 ist neuer Default
Was: Der "Fast Mode" im Claude Code CLI nutzt nun standardmässig das Modell Opus 4.7, ein Upgrade von der bisherigen Version 4.6.
Impact fuer Dave: Du erhältst automatisch die Leistung und Fähigkeiten des neueren Modells für deine schnellen Anfragen im CLI, ohne etwas ändern zu müssen.
Action: Nichts tun
Datum: Mai 2026
Quelle: [Releases · anthropics/claude-code - GitHub](https://github.com/anthropics/claude-code/releases)

### Gemini API: Multimodales File Search
Was: Das File Search Tool der Gemini API unterstützt jetzt multimodale Suchen, sodass Bilder und Text gemeinsam verarbeitet und durchsucht werden können.
Impact fuer Dave: Du kannst RAG-Systeme bauen, die nicht nur Text, sondern auch Bildinhalte verstehen, um z.B. visuelle Assets anhand von Beschreibungen zu finden.
Action: Ausprobieren
Datum: 05.05.2026
Quelle: [Gemini API File Search is now multimodal: build efficient, verifiable RAG - Google Blog](https://blog.google/technology/ai/gemini-api-file-search-is-now-multimodal-build-efficient-verifiable-rag)

### Anthropic API: Neue Agent-Fähigkeiten (Dreaming, Orchestration)
Was: Anthropic hat für "Claude Managed Agents" neue Fähigkeiten wie "Dreaming" (ein Langzeitgedächtnis, das aus vergangenen Sessions lernt) und Multi-Agent-Orchestrierung eingeführt.
Impact fuer Dave: Wenn du komplexere, stateful Agenten baust, kannst du diese neuen API-Features für robustere und intelligentere Automatisierungen nutzen, bei denen ein Haupt-Agent Aufgaben an Spezialisten-Agenten delegiert.
Action: Ausprobieren
Datum: 07.05.2026
Quelle: [Anthropic Claude update, May 2026](https://fazm.com/2026/05/16/claude-update-may-2026/)
