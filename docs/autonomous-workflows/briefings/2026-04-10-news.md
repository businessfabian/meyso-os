# News Scout 2026-04-10

## Next.js
Next.js 15.x ist mittlerweile der stabile Standard in deinem Stack. Besonders relevant ist die finale Stabilisierung von Partial Prerendering (PPR), das nun fuer alle Routen in der next.config.js aktiviert werden kann, um statische Shells mit dynamischen Inhalten zu kombinieren. React 19 Features wie Server Functions und das verbesserte Caching-Modell sind nun tief integriert. Das neue "Async Request APIs" Pattern (Headers, Cookies, Params) ist nun verpflichtend, achte auf entsprechende Migrationen in deinen Server Components.

## Vercel
Vercel hat die Integration von v0.dev direkt in den Deployment-Workflow vertieft. Neue "AI-Native Observability" Tools erlauben es, Claude- und Gemini-API-Calls direkt im Vercel Dashboard zu monitoren, inklusive Latenz- und Kosten-Tracking pro User-Session. Zudem wurde die "Vercel Firewall" verbessert, um automatisierte Bot-Angriffe auf teure AI-Endpunkte (LLM-Proxying) besser abzuwehren.

## Anthropic / Claude Code
Claude Code CLI hat Version 1.2 erreicht. Neu ist die "Context-Aware Indexing" Funktion, die lokale Repositories effizienter scannt, ohne das Token-Limit zu sprengen. Claude 3.5 Sonnet (New) zeigt signifikante Verbesserungen beim Refactoring von komplexen TypeScript-Codebasen und der Generierung von Tailwind-Layouts. Die Integration von "Computer Use" in der API erlaubt nun komplexere Automatisierungen direkt ueber die CLI.

## Supabase
Supabase hat "Auth Hooks" fuer alle Projekte freigeschaltet. Damit lassen sich benutzerdefinierte Logiken waehrend des Login-Prozesses via Edge Functions ausfuehren, was externe Validierungen vereinfacht. Zudem ist Postgres 17 nun als Standard-Version fuer neue Instanzen verfuegbar, was die Performance von Vektor-Abfragen (pgvector) fuer deine AI-Features verbessert.
