## Findings

### CVE-2026-23869: Next.js Security Advisory (App Router, 13.x bis 16.x)

Was: Neue High-Severity Vulnerability in React Server Components (DoS via App Router). Betrifft Next.js 13.x bis 16.x inkl. Daves aktueller Version 16.1.6. Vercel hat Platform-Mitigations deployed, empfiehlt aber Upgrade auf gepatchte Version.
Impact fuer Dave: Alle Projekte mit App Router (meyso-website, hirmax, sq-schmidt, kmu-template) sind betroffen bis gepatchte Version eingespielt ist.
Action: Dringend updaten
Datum: April 2026
Quelle: [CVE-2026-23869 Summary bei Vercel](https://vercel.com/changelog/summary-of-cve-2026-23869)

### Claude Code 2.1.98: Monitor-Tool und Security-Fixes

Was: Claude Code 2.1.98 bringt ein neues Monitor-Tool fuer Streaming-Events aus Background-Scripts, Subprocess Sandboxing mit PID-Namespace-Isolation (Linux) und mehrere Security-Fixes (Bash permission bypass, compound commands, /dev/tcp redirects). Ausserdem `/powerup` fuer interaktive Feature-Lektionen.
Impact fuer Dave: Monitor-Tool direkt nutzbar in autonomen Loops. Security-Fixes per `npm update -g @anthropic-ai/claude-code` einspielen.
Action: Ausprobieren
Datum: April 2026
Quelle: [Claude Code CHANGELOG.md](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)

---

### Gemini 3 Flash Preview: Neuere Generation als 2.5-flash verfuegbar

Was: Gemini 3-Serie ist jetzt verfuegbar: `gemini-3-flash-preview` (Frontier-Klasse bei niedrigeren Kosten) und `gemini-3.1-flash-lite-preview` als neuere Alternativen zu Daves aktuellem `gemini-2.5-flash`.
Impact fuer Dave: Die autonomen Loops laufen auf gemini-2.5-flash. Ein Test-Upgrade auf gemini-3-flash-preview koennte bessere Performance bei gleichen oder niedrigeren Kosten bringen.
Action: Ausprobieren
Datum: April 2026
Quelle: [Gemini API Models](https://ai.google.dev/gemini-api/docs/models)

---

### Gemini API: Spend Caps seit 01.04.2026 aktiv + neue Flex/Priority Tiers

Was: Seit 01.04.2026 werden Tier-Spend-Caps enforced (Tier 1 = max $250/Monat). Zusaetzlich neue Inferenz-Optionen "Flex" (guenstiger, hoehere Latenz) und "Priority" (Echtzeit) verfuegbar.
Impact fuer Dave: Autonomous Loops mit Gemini Flash koennen an die Grenze stossen. "Flex" Tier fuer nicht-zeitkritische Loops evaluieren um Kosten zu senken.
Action: Ausprobieren
Datum: 01.04.2026
Quelle: [Gemini API Billing Docs](https://ai.google.dev/gemini-api/docs/billing)

---

### Next.js 16.2: 400% schnellerer Dev-Start, stable Adapter API

Was: Next.js 16.2 vom 18.03.2026 bringt ~400% schnelleren `next dev` Start, ~50-60% schnelleres Server-Component-Rendering (React-Contribution), stable Adapter API fuer non-Vercel Deployments und 200+ Turbopack Fixes.
Impact fuer Dave: Direkter Dev-Experience-Gewinn auf allen Projekten, kein Breaking Change von 16.1.6 auf 16.2.
Action: Ausprobieren
Datum: 18.03.2026
Quelle: [Next.js 16.2 Blog](https://nextjs.org/blog/next-16-2)
