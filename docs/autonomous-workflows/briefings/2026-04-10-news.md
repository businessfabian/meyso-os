# News Scout 2026-04-10

## Next.js
Next.js hat vor kurzem Version 15.2 (Canary) und die stabilen Updates für 15.1 veröffentlicht. Der Fokus liegt auf der vollständigen Stabilisierung des Next.js Compilers (Turbopack) für den Production-Build sowie erweiterten Support für React 19 Features wie Server Components und Actions.
Link: https://github.com/vercel/next.js/releases
Link: https://nextjs.org/blog/next-15-1

## Vercel
Vercel hat das AI SDK 4.0 gelauncht. Dieses Update bringt signifikante Verbesserungen für "Agentic Workflows" und eine vereinfachte Integration von Multi-Modalen Modellen (Text, Bild, Audio). Zudem wurde "Vercel Secure Compute" für serverlose Datenbankverbindungen optimiert.
Link: https://vercel.com/blog/ai-sdk-4-0
Link: https://vercel.com/changelog

## Anthropic / Claude Code
Anthropic hat das Modell Claude 3.7 Sonnet veröffentlicht, das neue Maßstäbe in der Coding-Performance setzt. Zeitgleich wurde "Claude Code" (CLI) offiziell aus der Beta entlassen. Es ermöglicht agentenbasiertes Coding direkt im Terminal, inklusive File-Editing, Test-Execution und Git-Integration.
Link: https://www.anthropic.com/news/claude-3-7-sonnet
Link: https://docs.anthropic.com/en/docs/agents-and-tools/claude-code

## Supabase
Supabase hat neue "Auth Hook" Funktionen für SMS-Provider und verbesserte "Index Advisors" in der Dashboard-UI eingeführt. Zudem gibt es Updates für die Supabase-Vercel-Integration, die das Environment-Variable-Management bei Branch-Deployments automatisiert.
Link: https://supabase.com/blog
Link: https://github.com/supabase/supabase/releases

## Sanity CMS
Sanity Studio v3.72.0 wurde veröffentlicht. Das Update enthält verbesserte "Visual Editing" Features für Next.js App Router Projekte und eine performantere Handhabung von sehr großen Dokumenten-Listen im Desk Tool.
Link: https://www.sanity.io/changelog
