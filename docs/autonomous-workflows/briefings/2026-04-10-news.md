# News Scout 2026-04-10

## Next.js
In den letzten Wochen gab es signifikante Fortschritte in der Stabilität von Next.js 14.2 und erste Ausblicke auf Version 15.
- **Next.js 14.2.3:** Dieses Release konzentriert sich auf die Stabilisierung von Turbopack (beta) und Verbesserungen beim Caching sowie der Build-Performance.
- **Turbopack:** Die Unterstützung für Entwicklungs-Builds wurde erheblich verbessert, um die Startzeiten in großen Repositories zu reduzieren.
- **Changelog:** [Next.js 14.2 Release Notes](https://nextjs.org/blog/next-14-2) und [GitHub Releases](https://github.com/vercel/next.js/releases)

## Vercel
Vercel hat im Rahmen der "Vercel Ship" Ankündigungen neue Features für die Developer Experience und KI-Integration veröffentlicht.
- **Vercel AI SDK 3.1:** Einführung von "Generative UI", womit Komponenten direkt aus dem LLM-Stream gerendert werden können. Dies ist besonders relevant für die Arbeit mit Claude und Gemini.
- **Vercel Toolbar:** Neue Funktionen für Interaction Testing und verbesserte Feedback-Loops direkt im Browser.
- **Ankündigung:** [Vercel Ship 2024 Highlights](https://vercel.com/blog/vercel-ship-2024-announcements)

## Anthropic / Claude Code
Anthropic hat die Verfügbarkeit von erweiterten Funktionen für Entwickler massiv ausgebaut.
- **Tool Use (Function Calling) GA:** Die Fähigkeit von Claude, externe Tools und APIs aufzurufen, ist nun für alle Modelle der Claude 3 Familie (Opus, Sonnet, Haiku) allgemein verfügbar. Dies ist die Basis für komplexe "Claude Code" Implementierungen.
- **Claude 3.5 Gerüchte:** Es gibt vermehrt Hinweise auf Performance-Optimierungen bei der Verarbeitung von langem Kontext (200k+ Tokens).
- **Blogpost:** [Anthropic Tool Use General Availability](https://www.anthropic.com/news/tool-use-ga)

## Supabase
Supabase hat den Meilenstein der "General Availability" (GA) erreicht und neue Enterprise-Features vorgestellt.
- **Supabase GA:** Die Plattform wird nun offiziell als produktionsreif für kritische Enterprise-Workloads eingestuft.
- **Supabase Index Advisor:** Ein neues Tool, das direkt in das Dashboard integriert ist und SQL-Abfragen analysiert, um passende Indizes vorzuschlagen.
- **Changelog:** [Supabase GA Announcement](https://supabase.com/blog/supabase-ga)

## Sanity CMS
Sanity hat die visuelle Bearbeitung und die Performance des Studios optimiert.
- **Sanity Studio v3.44.0:** Verbesserungen beim "Visual Editing" in Kombination mit Next.js App Router und Updates für die Präsentation von Dokumenten-Historien.
- **Release Notes:** [Sanity Studio Changelog](https://github.com/sanity-io/sanity/releases)
