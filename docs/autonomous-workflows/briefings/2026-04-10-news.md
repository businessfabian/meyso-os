Was: Claude Code hat neue Features: `/powerup` (interaktive Lernlektionen mit animierten Demos), automatische Checkpoints vor jeder Aenderung (Esc+Esc oder `/rewind` zum Zurueckrollen) und eine VS Code Extension in Beta.

### CVE-2026-23869: Next.js Security Advisory (App Router, 13.x bis 16.x)

Was: Neue High-Severity Vulnerability in React Server Components (DoS via App Router). Betrifft Next.js 13.x bis 16.x inkl. Daves aktueller Version 16.1.6. Vercel hat Platform-Mitigations deployed, empfiehlt aber Upgrade auf gepatchte Version.
Impact fuer Dave: Alle Projekte mit App Router (meyso-website, hirmax, sq-schmidt, kmu-template) sind betroffen bis gepatchte Version eingespielt ist.
Action: Dringend updaten
Datum: April 2026
Quelle: [CVE-2026-23869 Summary bei Vercel](https://vercel.com/changelog/summary-of-cve-2026-23869)

---

### Gemini API: Billing Spend Caps seit 01.04.2026 aktiv

Was: Seit 01.04.2026 werden Tier-Spend-Caps enforced. Tier 1 = max $250/Monat ueber den gesamten Billing Account. Wenn Cap erreicht, werden alle API Requests pausiert bis zum naechsten Billing-Cycle (ca. 10 Minuten Delay beim Enforcement).
Impact fuer Dave: Autonomous Loops mit Gemini Flash koennen bei intensiver Nutzung an die Grenze stossen. Projekt-Level Spend Cap im AI Studio setzen empfohlen.
Action: Ausprobieren
Datum: 01.04.2026
Quelle: [Gemini API Billing Docs](https://ai.google.dev/gemini-api/docs/billing)

---

### Next.js 16.2: Stable Adapter API und Agent DevTools

Was: Next.js 16.2 vom 18.03.2026 bringt stable Adapter API fuer non-Vercel Deployments, Browser Log Forwarding, experimentelle Agent DevTools und ueber 200 Turbopack Fixes.
Impact fuer Dave: Minor Upgrade von 16.1.6 auf 16.2. Agent DevTools koennte fuer Debugging der Autonomous Loops nuetzlich sein.
Action: Ausprobieren
Datum: 18.03.2026
Quelle: [Next.js 16.2 Blog](https://nextjs.org/blog/next-16-2)

### Supabase: Stripe Sync Engine und PostgREST v14

Was: PostgREST v14 liefert ca. 20% mehr GET-Requests pro Sekunde. Neue One-Click Stripe Sync Engine direkt im Supabase Dashboard erlaubt SQL-Queries auf Stripe-Daten (Customers, Subscriptions, Invoices).
Impact fuer Dave: Stripe Sync Engine ist relevant wenn Hirmax Payment Processing mit Stripe umgesetzt wird. PostgREST v14 Rollout ist automatisch, kein Action-Bedarf.
Action: Ausprobieren
Datum: April 2026
Quelle: [Supabase Changelog](https://supabase.com/changelog)
