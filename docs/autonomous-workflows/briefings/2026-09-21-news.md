### SECURITY: Supabase Auth OIDC Token Bypass (CVE-2026-31813)
**Was:** Versionen von supabase/auth (GoTrue) vor 2.185.0 erlauben unter Umständen Account-Übernahmen durch manipulierte OIDC ID-Tokens, wenn Apple oder Azure als Authentifizierungs-Provider aktiviert sind.
**Impact für Dave:** Wenn du Apple oder Azure Authentifizierung für deine Projekte nutzt, könnten User-Accounts angreifbar sein.
**Action:** Dringend updaten
**Datum:** 16.09.2026
**Quelle:** [Supabase Security Issues 2025 - 2026: Fix Critical Vulnerabilities](https://decloak.dev/guides/supabase-security-issues)

### BREAKING: Supabase Management API `logs.all` Endpoint wird entfernt
**Was:** Der `logs.all` Endpoint der Management API wird am 23. September 2026 vollständig entfernt. Skripte müssen auf den neuen `logs` Endpoint migriert werden, der ausschließlich ClickHouse SQL akzeptiert.
**Impact für Dave:** Falls du Skripte hast, die Logs über die Management API abfragen, werden diese nach dem Stichtag fehlschlagen.
**Action:** Dringend updaten
**Datum:** Deadline 23.09.2026
**Quelle:** [Changelog - Supabase](https://supabase.com/changelog/managent-api-logs-all-deprecation)
