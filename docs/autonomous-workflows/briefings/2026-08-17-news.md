### [UNVERIFIED] Claude Code CLI Updates bis v2.1.228

*   **Was:** Mehrere Updates für das Claude Code CLI wurden veröffentlicht, mit der neuesten Version 2.1.228 vom 11. August 2026. Die Updates umfassen neue Befehle wie `/fork`, um eine Konversation im Hintergrund zu kopieren, und `/subtask` für In-Session-Subagenten. Zudem wurden zahlreiche Fehlerbehebungen und Verbesserungen an der Benutzeroberfläche und der internen Verarbeitung vorgenommen.

Die Fehlerbehebungen könnten die allgemeine Stabilität und Geschwindigkeit bei langen Sitzungen erhöhen.
